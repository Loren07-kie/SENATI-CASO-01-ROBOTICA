# SENATI — Caso 01: Pedidos de kits de robótica

Aplicación educativa Flask que predice pedidos semanales mediante regresión lineal múltiple. Se utilizan datos simulados y tres entradas: consultas web, inversión publicitaria y campaña escolar.

## Ejecutar

```bash
pip install -r requirements.txt
python app.py
```

Para Render: `pip install -r requirements.txt` y `gunicorn app:app`, plan Free.

Los resultados son estimaciones educativas, no ventas garantizadas.
