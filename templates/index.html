Scikit-learn encuentra un intercepto y tres coeficientes. Cada uno representa cuánto cambia el costo estimado cuando cambia un factor, manteniendo los otros constantes.

Flask recibe los valores, calcula el resultado con la fórmula y muestra una descomposición entendible del total. No hace falta JavaScript.

LA ECUACIÓN DETRÁS DE TODO

¿Por qué el camino cambia el precio?

El modelo encontró relaciones positivas para kilómetros, kilos transportados y vías no asfaltadas. Según esta muestra, una carretera no asfaltada añade aproximadamente S/ {{ '%.2f'|format(coeficientes.via_no_asfaltada) }} al mismo recorrido y carga.

Costo ≈ {{ '%.2f'|format(intercepto) }} + {{ '%.4f'|format(coeficientes.distancia_km) }} × km + {{ '%.4f'|format(coeficientes.carga_kg) }} × kg + {{ '%.2f'|format(coeficientes.via_no_asfaltada) }} × vía

«Vía» vale 0 si está asfaltada y 1 si no está asfaltada. Esta ecuación describe asociaciones aprendidas, no demuestra causalidad.

04 / CALIDAD Y LÍMITES

¿Podemos confiar ciegamente?

📉

MAE = S/ {{ '%.2f'|format(metricas.mae) }}

En los 26 viajes de prueba, el error absoluto medio fue de unos S/ {{ '%.2f'|format(metricas.mae) }}. Es un promedio, no un error máximo.

📈

R² = {{ '%.4f'|format(metricas.r2) }}

El modelo explica aproximadamente {{ '%.1f'|format(metricas.r2 * 100) }} % de la variación observada en ese conjunto de prueba, pero puede fallar en viajes reales.

¿Por qué se utiliza regresión lineal múltiple?

Porque queremos predecir un valor numérico (soles) usando tres variables. El algoritmo combina sus coeficientes para obtener un costo aproximado.

¿Cómo podría disminuir el margen de error?

Con datos reales suficientes, mejor registro de costos, más variables relevantes, validación cruzada y una comparación justa de algoritmos sin usar los datos de prueba durante el entrenamiento.

¿Qué representa el recargo de la vía no asfaltada?

Es el coeficiente asociado a pasar de 0 a 1 en la variable tipo de vía, manteniendo constantes los kilómetros y la carga. Es una relación estadística del conjunto de datos simulado.
