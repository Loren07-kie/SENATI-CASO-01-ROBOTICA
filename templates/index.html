04 · ¿POR QUÉ FUNCIONA?

Explicación sencilla del modelo

Porque aprende patrones

El modelo observa ejemplos anteriores y detecta cómo se relacionan las entradas con los pedidos. Si aumentan las consultas y la publicidad, normalmente también sube la predicción.

Porque cada variable aporta algo distinto

Las consultas web representan el interés, la publicidad impulsa visibilidad y la campaña escolar agrega un efecto extra. Al combinarse, producen una estimación más útil que usar una sola variable.

Porque la regresión estima una tendencia

No adivina el futuro con certeza total. Lo que hace es calcular una tendencia probable a partir de los datos de entrenamiento. Por eso sirve como apoyo para decidir, no como garantía absoluta.

¿Qué significa MAE?

Es el error absoluto medio. Nos dice cuántos pedidos se equivoca el modelo, en promedio, cuando hace predicciones con los datos de prueba.

¿Qué significa R²?

Indica qué tan bien la variación de los datos es explicada por el modelo. Mientras más se acerque a 1, mejor suele ajustarse a la información evaluada.

¿La predicción siempre se cumple?

No. Es una estimación educativa basada en datos simulados. Sirve para comprender el proceso de modelado y apoyar decisiones, no para garantizar ventas reales.
